# CapaBuddies

This was my first hackathon project, created in 2024 for the Hacker Olympians
stream at SheHacks+8. CapaBuddies is a fun facts website about capybaras along with a storefront demo,
with a playful jungle adventure theme.

Contributors: Faria Islam, Lindsay Torres and Nusrat Jahan.

## Demo

[Watch the CapaBuddies demo on Google Drive](https://drive.google.com/file/d/1EvkNeP-u-HGjm_azXuR67plZIFjPgEc6/view?usp=sharing)

## Project structure

- The HTML pages are in the project root; open `index.html` to start.
- `css/` contains the stylesheets.
- `assets/images/` contains the local images and animations.
- `assets/videos/` contains the project demo video.
